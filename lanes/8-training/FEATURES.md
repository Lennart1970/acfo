# Lane 8 — Features (training)

## Curriculum tracks

| Track | Audience | Outcomes |
| --- | --- | --- |
| Colony basics | All contributors | Lanes, STATUS discipline, labels, no-secrets rule |
| Platform map | Builders | Stack pieces, environments, where to look (lane 1) |
| Agent builder | Makers / agent authors | Loops, tools, grounding, packaging (lane 2) |
| Connector & data | Engineers | Contracts, SoR vs SoW, least privilege (lanes 3 / 4 / 6) |
| ALM | Release operators | Export, version, promote (lane 5) |
| Evaluation | Quality owners | Scores, KPIs, override learning (lane 7) |
| Operator / user | People running agents day-to-day | Supervise, escalate, approve write-backs safely |

## Artefact types

- Short Markdown modules and checklists in-repo  
- Links to external labs or sandboxes (no live credentials)  
- Optional workshop outlines that stay domain-agnostic  

## Explicit non-features

- No client workshops or product sales decks as colony canon  
- No recorded sessions that expose tenant data
